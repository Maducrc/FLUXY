# FLUXY

### Plataforma de Colaboração e Gestão de Equipes

A **Fluxy** é uma plataforma web desenvolvida como proposta prática do TCC **“Cultura de Colaboração e Tecnologia: Métodos Ágeis e Trabalho em Equipe”**.

A plataforma busca fortalecer a colaboração entre equipes por meio de recursos como **comunicação entre setores, organização de tarefas, acompanhamento de atividades, calendário compartilhado e metodologias ágeis**.

## Tecnologias

| Tecnologia     | Utilização                       |
| -------------- | -------------------------------- |
| **HTML5**      | Estrutura da aplicação           |
| **CSS3**       | Estilização e responsividade     |
| **JavaScript** | Interatividade e funcionalidades |
| **Python**     | Desenvolvimento e integração     |
| **MySQL**      | Banco de dados                   |
| **APIs**       | Integração entre sistemas        |
| **IA**         | Tecnologia de apoio              |
